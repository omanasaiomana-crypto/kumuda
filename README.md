# AURA MED — Dr. Kumuda N.V's Tribute & Memory Vault 🌟🩺

An interactive, cinematic web experience celebrating the journey of **Dr. Kumuda N.V** — from school days with her besties (Omana, Daanvi & Druthi) to transforming into an inspiring medical professional.

## ✨ Features

- **Cinematic Scrollytelling Experience**: 300 ultra-HD frames smoothly rendered alongside high-definition video narration.
- **Interactive Timeline & Memory Chapters**:
  - Chapter 1: *The Spark & The White Coat Dream*
  - Chapter 2: *The Unbreakable Bond (The Four of Us)*
  - Chapter 3: *Soul Sisters & Enduring Memories*
  - Chapter 4: *Family Pride & The Journey Ahead*
- **Interactive Polaroid Memory Wall**: Leave heartfelt notes, pin photos, and react to cherished memories.
- **Responsive & Immersive Audio/Visual Design**: Polished typography, ambient soundscapes, fluid animations, and high-performance frame playback.

## 🚀 Getting Started

To view the website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/omanasaiomana-crypto/kumuda.git
   cd kumuda
   ```

2. Open with any local web server (e.g. Node, Python, or VS Code Live Server):
   ```bash
   # Using Node.js server included:
   node server.js

   # Or using Python:
   python -m http.server 8000
   ```

3. Open `http://localhost:8000` (or `http://localhost:3000`) in your browser.

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Custom design tokens, CSS Grid & Flexbox, responsive layouts)
- **Vanilla JavaScript** (Frame scrubbing, video sync, scroll physics, interactive canvas)
- **Express.js / Node.js** (Optional lightweight backend server)
